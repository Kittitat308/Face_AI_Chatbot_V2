# Face_AI_Chatbot_V2

แอป Desktop แบบผู้ใช้ทีละหนึ่งคน พัฒนาด้วย PySide6 ใช้ SCRFD (ผ่าน InsightFace `buffalo_l`) ตรวจจับใบหน้า, ArcFace จดจำใบหน้า, Gemini ตอบแชท, PostgreSQL เก็บผู้ใช้และประวัติแชท, whisper.cpp รับเสียง และ PyThaiTTS Vachana เสียงผู้หญิง `th_f_2` สำหรับเสียงต้อนรับ

## ความสามารถหลัก

- Login ด้วยใบหน้าแล้วเข้าหน้า Chatbot ทันที หรือเลือกถามรหัสผ่านหลัง Face Recognition แยกเป็นรายบัญชีได้
- เข้าสู่ระบบสำรองด้วยชื่อบัญชี/อีเมลและรหัสผ่านได้เมื่อกล้องไม่พร้อม
- ชื่อบัญชีเป็นชื่อเดียวกับชื่อที่แสดงใน Chatbot/TTS รองรับภาษาไทยและ Unicode โดย normalize เป็น NFC, ต้องไม่ซ้ำ, เขียนติดกันโดยไม่มี whitespace/อักขระแฝง และตอน Login ต้องใช้ตัวพิมพ์เล็ก–ใหญ่ให้ตรงกับข้อมูลที่สมัคร
- รหัสผ่านเก็บด้วย scrypt และล็อกบัญชีชั่วคราวเมื่อกรอกผิดซ้ำ
- ลงทะเบียนใบหน้า 5 ตัวอย่าง ทุก 5 วินาที
- หน้าแชทสไตล์ ChatGPT แยกประวัติตามผู้ใช้ เพิ่มและลบแชทได้
- ปุ่มไมค์บันทึกเสียงและถอดข้อความภาษาไทยด้วย whisper.cpp
- โหลด VachanaTTS ให้พร้อมก่อนแสดงหน้า Login
- เตรียมเสียงต้อนรับเฉพาะผู้ใช้ก่อนเปลี่ยนหน้า แล้วเล่นทันทีหลังหน้า Chatbot แสดง
- แก้ profile, ตั้งรหัสผ่านใหม่ และ logout ได้
- หลัง Login เปิดกล้องหนึ่ง instance และตรวจ current user ใน background ทุก 60 วินาที; ไม่พบหน้า 5 รอบจะแสดง modal countdown 5 วินาทีและเร่งตรวจทุก 1 วินาที
- หน้า Settings มีสวิตช์กล้อง ไมโครโฟน และลำโพงแยกตามบัญชี; หากอุปกรณ์ไม่พร้อม ระบบยังใช้ Manual Login และ Text Chat ต่อได้
- Current user มี priority สูงสุดและรีเซ็ต miss count; Unknown เพิ่ม miss count; registered user คนอื่นเพียงคนเดียวต้องตรงกัน 2 รอบติดก่อน switch account; หลายใบหน้าที่ไม่มี current user แต่มี Unknown จะเพิ่ม miss count ส่วนหลายใบหน้าที่เป็น registered users อื่นทั้งหมดจะ logout ทันที
- หากกล้องไม่พร้อมหรือหยุดส่งภาพ ระบบจะปิด auto-logout ชั่วคราวและให้ใช้งาน Chatbot ต่อ

## เริ่มใช้งาน

1. สร้างฐานข้อมูล PostgreSQL ชื่อ `face_ai_chatbot` (ใช้ `sql/create_database.sql` ได้)
2. คัดลอก `.env.example` เป็น `.env` แล้วใส่ `DATABASE_URL` และ `GEMINI_API_KEY`
3. ติดตั้งแพ็กเกจด้วย `pip install -r requirements.txt`
4. ตรวจว่าไฟล์ `whisper-cli.exe` และ `ggml-small.bin` อยู่ใน `app/services/STT/`
5. เริ่มแอปด้วย `python run.py`

แอปจะเพิ่มคอลัมน์ใหม่ในตารางเดิมให้อัตโนมัติ ผู้ใช้จากฐานข้อมูลรุ่นเดิมที่ยังไม่มีรหัสผ่านสามารถสแกนใบหน้าแล้วกด “ลืมรหัสผ่าน” เพื่อตั้งรหัสครั้งแรกได้

## หมายเหตุด้านความปลอดภัย

ระบบใช้การตรวจจับใบหน้าแบบค่าเริ่มต้นของ InsightFace เพื่อให้ลงทะเบียนและเข้าสู่ระบบได้ง่ายขึ้น กล้อง RGB ทั่วไปไม่สามารถรับประกันการป้องกันภาพ/วิดีโอปลอมระดับสูงสุดได้ หากใช้ในงานความเสี่ยงสูงควรเพิ่มกล้อง depth/IR และโมเดล face anti-spoofing ที่ผ่านการประเมินจริง รวมถึงเข้ารหัสฐานข้อมูลและใช้ TLS สำหรับ PostgreSQL

ชื่อโมเดลใน PyThaiTTS อย่างเป็นทางการคือ `vachana` และเสียงผู้หญิงลำดับที่ 2 คือ `th_f_2` (ใช้แทนคำเรียก “wachana2”)
